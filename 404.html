BACKUP & RESTORE

Protect your history

A full JSON backup contains your meals, custom foods, goals, morning/night weights, and complete daily history. CSV is useful for viewing your data in Excel or Google Sheets.

Automatic local safety snapshots
The app keeps up to 7 rolling snapshots in browser storage whenever your data changes. These are a second line of defense, but they do not replace downloading a backup file.

INSTALL AS AN APP

PWA ready

When this tracker is opened from an HTTPS web address, it can be installed to your phone's home screen and can continue opening offline. The raw downloaded HTML file itself cannot register a service worker, so install/offline mode activates after the app is hosted.

FREE HOSTING READY
This package is already prepared for static HTTPS hosting. No server or database is required. GitHub Pages, Cloudflare Pages, and Netlify can all host this version without changing the tracker code.
