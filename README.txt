BACKUP
Use Backup & Install > Export Full Backup regularly.
Use Import Backup to restore everything.
CSV export creates a spreadsheet-friendly history file.

PWA / OFFLINE
Service workers require HTTPS or localhost. Opening index.html directly from your Downloads folder will still run the tracker,
but browser installation and offline caching will not activate.

FREE HOSTING
This package is ready for any static HTTPS host, including free tiers such as GitHub Pages, Cloudflare Pages, or Netlify.
No database is required for the current version.

IMPORTANT
Until cloud sync is added, data remains device/browser-specific. Keep periodic JSON backups somewhere outside the browser.
